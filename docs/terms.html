Ketentuan Penggunaan BLINK

Draf ketentuan: wajib ditinjau dan dilengkapi pemilik bisnis sebelum peluncuran komersial, termasuk identitas operator, kebijakan refund, sengketa, dan perlindungan konsumen.

Layanan

BLINK menyediakan kamera browser, Live Photo sebagai berkas foto dan klip video, filter media lokal, serta pemrosesan AI melalui backend GPU ketika layanan tersedia. Perbaikan visual tidak menjamin pemulihan sempurna dari sumber buruk. Resolusi hasil 4K tidak selalu berarti detail asli 4K.

Akun dan token

Sesuai konfigurasi backend: 3 token gratis per hari WIB, tanpa akumulasi. Foto AI 1 token, Live Photo AI 2 token, video AI 3 token. Paket Rp20.000 memberi 20 token Premium selama 30 hari setelah admin memverifikasi pembayaran, tanpa perpanjangan otomatis.

Pembayaran

QRIS bersifat manual. Bukti transfer harus diperiksa operator melalui penerimaan dana sebenarnya. Bukti unggahan saja tidak memberi Premium.

Media dan hak pengguna

Pengguna hanya boleh menggunakan media yang memiliki hak/izin. Hindari file ilegal, merugikan, atau mengandung data privat tanpa persetujuan. Hasil AI dapat mengubah detail wajah maupun objek; verifikasi hasil sebelum penggunaan penting.
